# Telegram Bot Setup & Staff Management Guide — TovMuk Solution

This guide provides a comprehensive 10-step process to set up, authorize, connect, and manage your Telegram store bot for client production deployments.

---

## 10-Step Client Bot Setup Process

### Step 1: Create a Telegram Bot in BotFather
1. Open Telegram and search for [@BotFather](https://t.me/BotFather).
2. Send `/newbot` and follow the instructions to set the bot display name and username.
3. Copy the HTTP API token generated by BotFather (e.g. `8422414802:AAHtXUqbXFJ0f_...`).
4. Set the Mini App URL in BotFather via `/newapp` or Edit Bot -> Menu Button -> Web App URL pointing to your deployed HTTPS frontend URL.

### Step 2: Add Bot Token to Server Environment
In your server's `.env` or deployment platform environment settings:
```env
TELEGRAM_BOT_TOKEN=8422414802:AAHtXUqbXFJ0f_FQyT1yC77n1GDEiF-sTQo
VITE_STORE_SLUG=your-client-store-slug
AUTHORIZED_STAFF_IDS=123456789,987654321
```

### Step 3: Deploy or Start the Bot Service
Start the backend bot server locally or on serverless host:
```bash
# Local execution
npm run bot

# Self-test check
npm run bot:check
```

### Step 4: Add Bot to Client Private Order Group
1. Create a private Telegram Group for the client's store staff (e.g. `Client Store Orders`).
2. Add the bot to the group as a member.

### Step 5: Make the Bot an Administrator
1. In the Group Info settings, go to **Administrators**.
2. Add the bot as an **Admin** with permission to send messages and manage messages.

### Step 6: Identify Group ID & Bind Store (`/groupid` & `/connectstore`)
Inside the private order group:
- Send `/groupid` to display the group name and numeric chat ID (e.g. `-100123456789`).
- Send `/connectstore` (or `/connectstore [store_slug]`) directly inside the group chat.

### Step 7: Confirm Group Connection
If the store already had an existing group connected, the bot will ask for replacement confirmation.
Click **✅ Confirm Replace** to finalize binding. The bot will save the `order_group_id` directly to Supabase PostgreSQL and record an audit log entry.

### Step 8: Add Authorized Staff Telegram IDs
Ensure all staff members who manage the store have their Telegram user IDs added to `AUTHORIZED_STAFF_IDS` in `.env` or saved in the `store_staff` table in Supabase.

### Step 9: Test Staff Product & Order Management
In a private message with the bot, use the main button keyboard:
- 🛍 **Products**: List products, edit details, toggle active status, replace photo.
- ➕ **Add Product**: Follow guided steps (Name -> Price -> Stock -> Category -> Photo upload -> Preview & Save).
- 🗂 **Categories**: View & create new categories.
- 📦 **Orders**: View recent orders and update status (`Confirmed`, `Preparing`, `Shipping`, `Delivered`).

### Step 10: Submit Test Order & Verify Notification
1. Open the Telegram Mini App from the bot menu or web link.
2. Select a product, add to cart, fill customer checkout details, and submit order.
3. Verify that:
   - Order is saved to Supabase PostgreSQL.
   - Complete order notification (with customer info, items, delivery fee, total, and interactive status buttons) instantly arrives in the connected Telegram Group.

## Command Reference

| Command | Environment | Description |
| :--- | :--- | :--- |
| `/start` | Private Chat | Welcome screen with Open Store WebApp button |
| `/groupid` | Group Only | Display numeric Group ID and connection instructions |
| `/connectstore [slug]` | Group Only | Auto-connect current group to store record in database |
| `/products` | Staff DM | Manage store product catalog |
| `/addproduct` | Staff DM | Guided step-by-step wizard to create product with photo |
| `/orders` | Staff DM | View recent customer orders and update status |
| `/categories` | Staff DM | View and add store categories |
| `/cancel` | Any Chat | Cancel current interactive conversation step |
